# Laboratorios

Este directorio contiene los laboratorios presenciales del curso, desde **M01** hasta **M10**, reutilizando el mismo entorno de GitHub Codespaces.

Cada práctica indica:
- el objetivo técnico;
- los archivos mínimos necesarios;
- la herramienta de referencia;
- qué alternativas pueden utilizarse cuando no se use Kiro;
- la evidencia que debe obtenerse durante el ejercicio.

La dificultad se concentra en el razonamiento y en los controles de ingeniería, no en navegar por estructuras de archivos complejas.
