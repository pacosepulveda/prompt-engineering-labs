# Tool Catalog — M04

Todas las herramientas son ficticias, locales y read-only.

## get_service_owner

Obtiene el owner de un servicio y su runbook principal.

Arguments:

```json
{
  "service": "identity-api | billing-api | web-portal"
}
```

Side effects: none.

## get_runbook

Obtiene el runbook principal conocido para un servicio.

Arguments:

```json
{
  "service": "identity-api | billing-api | web-portal"
}
```

Side effects: none.
