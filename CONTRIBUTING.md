# Criterios para los laboratorios

Los laboratorios de este repositorio se diseñarán con estas reglas:

- se realizan durante las sesiones de clase;
- Codespaces es la ruta de referencia para evitar instalaciones locales;
- Kiro tendrá un papel relevante, pero no será la única herramienta del curso;
- se priorizarán ejercicios transferibles entre herramientas y modelos;
- cada laboratorio debe poder reiniciarse con facilidad;
- no se almacenarán claves, tokens ni credenciales en el repositorio;
- las soluciones del instructor no se publicarán en el repositorio de alumnos.
